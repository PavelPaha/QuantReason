# Артефакты прогонов

Подкаталоги с именами **`run_id`** по умолчанию в `.gitignore`, чтобы не засорять репозиторий сырыми прогонами.

Версионируются только явно включённые снапшоты успешных **полных** прогонов (для воспроизводимости сравнений).

| Каталог | Что это |
|---------|---------|
| `20260512_011545_78d599` | MATH-500 **`max_examples=50`**, **`seed=42`**: hybrid (**BF16 план** → **2-bit GPTQ** ответ). `summary.json`: `accuracy=0.54`, `parse_rate=0.66`. |
| `20260512_012442_a81368` | Тот же срез: **FP16** Qwen3-32B на **обеих** стадиях «план → ответ». `summary.json`: `accuracy=0.36`, `parse_rate=0.44`. |

В каждом каталоге: `config.json`, `traces.jsonl`, `judgements.jsonl`, `metrics.jsonl`, `timing.jsonl`, `summary.json`, `trace_checkpoints/wave_*.jsonl`.

Чтобы добавить новый сохранённый прогон, создай каталог здесь же и допиши исключения в **корневом** `.gitignore` по аналогии с этими `run_id`.
